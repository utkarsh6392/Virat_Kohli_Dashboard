# ICC Cricket Career - 15 Years | Power BI Dashboard

## Project Overview

The **ICC Cricket Career - 15 Years Dashboard** is an interactive Power BI dashboard designed to analyze a cricketer's career performance over a 15-year period.

The dashboard provides insights into overall career statistics, runs scored against different opponents, matches played against opponents, and yearly run trends.

Users can interact with the dashboard using year filters and visual-level interactions to explore career performance across different periods.

---

## Objectives

The main objectives of this dashboard are:

- Analyze overall cricket career performance.
- Track total matches played and total runs scored.
- Identify the highest individual score.
- Analyze the number of 50s and 100s scored.
- Calculate and display batting average.
- Compare runs scored against different opponents.
- Analyze the number of matches played against different opponents.
- Identify yearly trends in runs scored.
- Provide an interactive and easy-to-understand dashboard.

---

## Dashboard Features

### 1. Career KPI Cards

The dashboard contains important career-level KPIs:

- **Matches** - Total matches played.
- **Runs** - Total runs scored.
- **Highest** - Highest individual score.
- **50's** - Number of half-centuries.
- **100's** - Number of centuries.
- **Average** - Overall batting average.

These KPIs provide a quick overview of the player's career performance.

---
